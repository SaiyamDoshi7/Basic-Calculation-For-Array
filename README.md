# Smart Travel Planner

A simple JavaScript travel planner that takes user input for destinations, budget, and days, and then suggests trip type, hotel class, and provides a summary of the travel plan.

---

## 📋 Project Overview

Smart Travel Planner helps users to:

- Input multiple destinations  
- Input total budget and number of days  
- Classify the trip type based on budget  
- Classify the trip duration  
- Suggest a hotel class based on per-day spending  
- Provide a concise summary of what the trip might look like  

This project illustrates use of **functions**, **conditional logic**, **user prompts**, and **DOM / console output** in JavaScript.

---

## 🧠 Problem Definition

**Goal:** To guide a user in planning a travel itinerary by suggesting trip type, accommodation level, and summarizing the plan based on simple heuristics.

**Inputs:**
- Number of destinations  
- Names of destinations  
- Total travel budget  
- Number of travel days  

**Outputs / Suggestions:**
- List of destinations  
- Trip type (short domestic / long domestic / international)  
- Duration type (weekend / holiday / extended)  
- Suggested hotel class (budget / mid-range / luxury)  
- Travel summary statement  

**Assumptions & Limitations:**
- No rigorous input validation (e.g. for non-numeric inputs)  
- Budget thresholds (10,000, 50,000) are arbitrary and may need tuning  
- Doesn’t account for transportation, food, sightseeing costs  
- Factorial of large numbers may overflow JavaScript’s safe limit
